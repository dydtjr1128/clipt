# Clipt – Screenshot & Screen Recorder

> Clip anything on the web.

웹페이지를 원하는 범위만큼 캡처하거나 녹화하는 Chrome 확장 프로그램 (Manifest V3)

## 사용 흐름

툴바 아이콘 클릭 → 메뉴 목록 표시 → 기능 선택 → 범위 지정 → 결과 확인 및 저장

## 메뉴 구성

### 📸 스크린샷

- **보이는 화면 캡처**: 현재 화면을 바로 캡처
- **전체 페이지 캡처**: 자동으로 스크롤하며 페이지 전체를 한 장으로 캡처
- **요소 캡처**: 호버로 요소를 선택하고, 선택 패널에서 범위를 조정한 뒤 캡처
- **영역 캡처**: 드래그로 원하는 영역을 선택해서 캡처

### 🎬 녹화

- **탭 녹화**: 현재 탭 화면 전체를 녹화
- **영역 녹화**: 드래그로 선택한 영역만 녹화
- **요소 녹화**: 요소 캡처와 같은 방식으로 선택, 패널에서 녹화 시작
  - **요소 따라가기**(기본 켬): 녹화 중 스크롤하거나 요소가 움직여도 요소를 따라가며 녹화. 끄면 시작할 때의 화면 위치를 그대로 녹화
  - 영상 크기는 시작할 때의 요소 크기로 고정. 요소 크기가 바뀌면 비율을 지켜 가운데에 맞추고, 요소가 화면 밖으로 나가면 직전 화면을 유지

### ⚙️ 설정

- 이미지 포맷 (PNG / JPEG)
- 영상 포맷 (webm / mp4)
- 캡처 후 동작 (결과 페이지 열기 / 바로 다운로드 / 클립보드 복사)
- 녹화 옵션 (탭 오디오 포함, 카운트다운)

## 요소 선택 방식 (요소 캡처 / 요소 녹화 공통)

### 1단계: 호버

- 마우스를 움직이면 커서 아래 요소의 범위가 반투명 색상 박스로 표시됨
- 다른 요소로 이동하면 표시 범위도 즉시 바뀜
- 박스 옆에 태그명과 크기(예: `div.card 320×180`) 라벨 표시

### 2단계: 클릭으로 선택

- 클릭하면 캡처되지 않고 해당 요소가 **선택 상태로 고정**됨
- 선택된 요소는 호버 색상과 다른 색으로 표시
- 고정 후에는 마우스를 움직여도 선택이 바뀌지 않음
- 선택 중 클릭은 페이지 원래 동작(링크 이동 등)이 실행되지 않도록 막음

### 3단계: 선택 패널에서 미세조정

선택하면 화면에 별도 패널이 뜸 (드래그로 위치 이동 가능)

- **요소 경로**: `body > div > div.container > div.card > img` 형태로 표시
  - 현재 선택된 요소는 강조 표시
  - 경로의 항목을 클릭하면 해당 요소로 바로 이동
- **깊이 슬라이더**: 왼쪽은 상위 요소, 오른쪽은 하위 요소
  - 슬라이더를 움직이면 선택 범위가 실시간으로 바뀜
  - 현재 깊이 숫자 표시
- **선택 요소 정보**: 태그명, id/class, 크기
- **버튼**
  - 요소 따라가기 토글 (요소 녹화에서만 표시)
  - 캡처 (요소 녹화에서는 "녹화 시작")
  - 다시 선택 (1단계 호버 상태로 돌아감)
  - 취소

### 키보드 조작

- `↑` : 상위 요소로 이동
- `↓` : 하위 요소로 이동
- `←` / `→` : 같은 깊이의 이전 / 다음 요소로 이동
- `Enter` : 캡처 (또는 녹화 시작)
- `Esc` : 선택 해제 후 호버 상태로, 한 번 더 누르면 종료
- 키보드로 이동하면 슬라이더와 요소 경로도 함께 갱신됨

### 캡처 결과

- 색상 표시, 라벨, 선택 패널은 캡처 결과에 찍히지 않음

## 공통 기능

- 녹화 중 팝업에 녹화 시간과 중지 버튼 표시
- 결과 페이지에서 미리보기, 다운로드, 클립보드 복사
- 단축키 지원
- Esc로 언제든 취소
