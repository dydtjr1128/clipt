# Clipt 1.1.0

팝업에서 설치된 버전을 바로 확인할 수 있게 하고 머리글을 더 작게 다듬은 버전이다. 설정과 저장된 결과는 그대로 유지된다.

## 팝업

- 팝업 머리글의 이름 옆에 설치된 버전(`v1.1.0`)을 표시. 업데이트가 반영됐는지 `chrome://extensions`를 열지 않고 확인
- 머리글의 위아래 여백과 이름 글자를 줄여 머리글 높이를 낮춤. 메뉴가 더 위에서 시작

## 설치와 업데이트

[설치 안내](https://github.com/dydtjr1128/clipt/blob/v1.1.0/INSTALL.md) · [ZIP 다운로드](https://github.com/dydtjr1128/clipt/releases/download/v1.1.0/clipt.zip) · [개인정보 처리방침](https://github.com/dydtjr1128/clipt/blob/v1.1.0/PRIVACY.md)

압축 해제로 설치했다면 같은 폴더의 파일을 새 ZIP 내용으로 교체하고 `chrome://extensions`에서 새로고침한다. 설정과 저장된 결과는 유지된다. ZIP 체크섬은 **SHA256SUMS.txt**에 있다.
