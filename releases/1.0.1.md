# Clipt 1.0.1

녹화 안정성과 화면 표시를 다듬은 수정 버전이다. 새 기능은 없고, 설정과 저장된 결과는 그대로 유지된다.

## 녹화

- 작은 요소·영역을 녹화하면 영상이 최소 160px, 가로세로 4:1 이내가 되도록 여백을 두고 가운데에 담음(재생 컨트롤에 가려지지 않게)
- 96kHz 오디오 장치에서 MP4 녹화가 빈 파일이 되던 문제 수정
- 저장 중 중지를 여러 번 누르거나, 최대 길이 자동 중지와 겹치거나, 인코더·저장 오류가 나거나, 시작 직후 중지해도 그때까지의 결과를 보존
- 카운트다운 중 창 크기를 바꾸거나 위젯을 끌었을 때 녹화 범위가 어긋나거나 위젯이 영상에 찍히던 문제 수정
- 요소 따라가기 중 요소가 순간 이동하면 잘못된 정지 화면이 남던 문제 수정

## 캡처와 요소 선택

- 영역을 그린 뒤 화면 밖으로 스크롤하면 캡처 결과가 어긋나던 문제 수정
- 요소 선택을 Enter·↑·↓로 키보드만으로 시작, Shadow DOM 최상위 요소 사이에서도 ←/→ 이동
- 요소 경로가 넘칠 때 가려진 쪽 가장자리를 흐리게 표시해 글자가 중간에서 잘려 보이지 않게 함

## 화면

- 녹화 중 팝업의 "녹화 중지" 버튼 문구가 두 줄로 깨지던 문제 수정(단축키는 버튼 아래에 표시)
- 아이콘을 글꼴 기호 대신 SVG로 그려 OS·글꼴과 관계없이 같은 모양으로 보임
- 한국어 문장이 음절 중간에서 줄바꿈되지 않게 함

## 결과

- 저장 공간 한도보다 큰 최신 녹화 결과가 지워지지 않게 함
- "바로 다운로드"가 실패하거나 취소되면 결과 페이지를 열어 결과를 잃지 않게 함
- 좁은 창에서도 영상 재생 컨트롤 공간 확보

## 설치와 업데이트
