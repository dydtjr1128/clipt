# Clipt 1.1.1

캡처 중단과 짧은 녹화에서 생기던 문제를 고친 수정 버전이다. 새 기능은 없고, 설정과 저장된 결과는 그대로 유지된다.

## 캡처

- 전체 페이지 캡처를 시작한 직후 Esc를 누르면 무시되고 캡처가 끝까지 진행되던 문제 수정. 이제 캡처가 시작된 순간부터 Esc로 멈추고 페이지가 원래대로 돌아옴

## 녹화

- 소리를 켠 녹화를 시작하자마자 중지하면 결과 없이 오류로 끝나던 문제 수정. 컴퓨터가 바쁘거나 오디오 장치가 늦게 열릴 때 주로 생김. 이런 상황에서 바로 중지하면 저장이 몇 초 걸릴 수 있음
- 소리가 실제로 녹음되기 시작한 뒤에 녹화 중 표시와 타이머가 나타남. 소리를 켠 녹화는 시작이 잠깐(보통 1초 미만) 늦어질 수 있음
