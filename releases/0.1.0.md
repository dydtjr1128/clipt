# Clipt 0.1.0

첫 공개 릴리스. 웹페이지를 원하는 범위만큼 캡처하거나 녹화하는 Chrome 확장 프로그램(Manifest V3).

## 기능

- **스크린샷**: 보이는 화면, 전체 페이지(자동 스크롤 이어 붙이기), 요소, 영역
- **녹화**: 탭, 영역, 요소. 요소 녹화는 스크롤·이동에도 요소를 따라가는 "요소 따라가기" 지원
- **요소 선택**: 호버 → 클릭 고정 → 선택 패널에서 경로·깊이 조정, 키보드 조작
- **녹화 옵션**: MP4 / WebM(VP9·VP8·AV1), 24·30·60fps, 해상도 배율, 탭 소리·마이크, 카운트다운, 일시정지, 최대 길이, 녹화 중 표시(없음·테두리·위젯)
- **결과 페이지**: 미리보기, 다운로드, 클립보드 복사, 중단된 녹화 복구
- **단축키**: Alt+Shift+1~4(보이는 화면·영역·요소 캡처, 탭 녹화 시작/중지), `chrome://extensions/shortcuts`에서 변경
- **언어**: 한국어, 영어

## 권한과 개인정보

`activeTab`으로 사용자가 실행한 탭에만 접근하며 host 권한을 요구하지 않는다. 캡처·녹화 결과는 브라우저 안에만 저장하고 어떤 서버로도 보내지 않는다. 설정은 Chrome 동기화 저장소에 저장되어 Chrome 동기화를 켠 경우 사용자의 다른 기기와 동기화될 수 있다. 자세한 내용은 [PRIVACY.md](https://github.com/dydtjr1128/clipt/blob/v0.1.0/PRIVACY.md).

## 검증

정적 검사, 단위 테스트 153개, 확장을 실제로 로드한 E2E 87개(Windows·Linux CI)를 통과했다. 10분 이상 녹화 시 메모리, 1080p 30fps 유지, 탭 소리·마이크 믹싱은 실제 Chrome에서의 수동 확인이 남아 있다([#11](https://github.com/dydtjr1128/clipt/issues/11), [#12](https://github.com/dydtjr1128/clipt/issues/12)).
