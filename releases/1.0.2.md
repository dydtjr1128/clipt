# Clipt 1.0.2

본문만 따로 스크롤되는 페이지의 캡처를 고친 수정 버전이다. 새 기능은 없고, 설정과 저장된 결과는 그대로 유지된다.

## 캡처와 요소 선택

- 메일·문서 편집기·대시보드처럼 본문만 따로 스크롤되는 페이지에서 전체 페이지 캡처가 현재 화면만 담던 문제 수정. 본문 스크롤 영역 전체를 이어 붙이고, 영역 밖 머리글·메뉴는 빠진다고 결과 페이지에 알림
- 왼쪽 메뉴와 오른쪽 본문이 따로 스크롤되는 페이지는 본문을 고르고, body가 스크롤되는 페이지와 Shadow DOM으로 만든 앱 화면의 스크롤 영역도 캡처
- 스크롤 영역에 가려진 요소나 스크롤 영역 자체를 요소 캡처하면 영역을 스크롤해 전체를 담음. "일부 잘림"은 스크롤로 펼칠 수 없게 가려진 경우에만 표시
- 스크롤 영역 안의 sticky 머리는 한 번만 담고, 스크롤 스냅이 걸린 영역도 어긋나지 않게 이어 붙이며, 캡처 뒤 스크롤 위치는 원래대로
