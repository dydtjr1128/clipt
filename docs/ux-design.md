# Clipt UI/UX 설계

> 팝업, 페이지 위 오버레이, 선택 패널, 결과 페이지의 시각·상호작용 기준. 구조는 `docs/architecture.md`를 따른다.

## 1. 디자인 원칙

1. **방해하지 않는다**: 오버레이는 필요한 순간에만 나타나고, 끝나면 흔적 없이 사라진다. 페이지 스타일을 바꾸면 반드시 복원한다.
2. **결과를 믿을 수 있다**: 사용자가 화면에서 본 선택 범위가 곧 결과다. 확장 UI는 사용자가 켜지 않는 한 결과에 찍히지 않는다.
3. **예측 가능하다**: 같은 조작은 항상 같은 결과. 슬라이더 왕복은 원점으로 돌아오고, Esc는 언제나 한 단계 뒤로 간다.
4. **키보드만으로 끝난다**: 단축키로 시작해 방향키로 조정하고 Enter로 마친다. 마우스는 선택 사항.
5. **한 번에 하나**: 동시에 하나의 작업만 진행하고, 현재 상태를 배지·팝업이 항상 보여준다.
6. **실패해도 안전하다**: 오류가 나면 페이지를 원상 복구하고 사유와 다음 행동을 한 줄로 알려준다.

## 2. 디자인 토큰 (`src/styles/tokens.css`)

모든 컨텍스트(팝업·Shadow DOM 오버레이·결과 페이지)가 같은 토큰을 쓴다. 오버레이는 Shadow root 안에 토큰을 다시 선언해 페이지 CSS와 격리한다.

## 3. 팝업

크기 320×auto. 열릴 때 `job` 상태를 읽어 아래 화면 중 하나를 즉시 그린다. 로딩 스피너는 두지 않는다.

### 3.1 기본 (idle)

```text
┌──────────────────────────────────────────┐
│ ✂ Clipt                          ⚙  ⌨  │  ← 설정, 단축키 설정(chrome://extensions/shortcuts)
├──────────────────────────────────────────┤
│ 스크린샷                                  │
│  ▣  보이는 화면              Alt+Shift+1 │
│  ▤  전체 페이지                        – │
│  ◱  요소 선택                Alt+Shift+3 │
│  ⬚  영역 선택                Alt+Shift+2 │
├──────────────────────────────────────────┤
│ 녹화                                      │
│  ●  탭 녹화                  Alt+Shift+4 │
│  ⬚  영역 녹화                          – │
│  ◱  요소 녹화                          – │
├──────────────────────────────────────────┤
│  WebM VP9 · 30fps · 탭 소리         변경  │  ← 현재 녹화 프로파일 요약, 클릭 시 설정
└──────────────────────────────────────────┘
```

- 항목: 아이콘 20px + 라벨 + 오른쪽 단축키 힌트(`--c-fg-2`, 미할당은 `–`). 높이 36px, 호버 `--c-bg-2`, 포커스 링 2px `--c-accent`.
- 클릭 즉시 팝업이 닫히고 작업이 시작된다. 팝업 안에서 대기 화면을 보여주지 않는다.
- 첫 실행 시 항목 아래에 한 줄 힌트 "요소·영역 선택 중 Esc로 취소"를 3회까지 표시.

### 3.2 제한 페이지

메뉴 전체를 비활성(`opacity .45`)으로 두고 상단에 안내 바:

```text
│ ⓘ 이 페이지에서는 사용할 수 없어요        │
│   브라우저 내부 페이지와 웹스토어는         │
│   캡처가 제한돼요.                         │
```

### 3.3 선택 진행 중

```text
│ ◱ 요소를 선택하는 중                       │
│   페이지에서 요소를 클릭하세요. Esc 취소     │
│                        [ 취소 ]           │
```

### 3.4 녹화 중

```text
┌──────────────────────────────────────────┐
│ ● 녹화 중 · 영역                          │
│                                           │
│            00:42                          │  ← 32px, tabular-nums, 매초 갱신
│   "GitHub - dydtjr1128/clipt"             │  ← 대상 탭 제목(말줄임)
│   1280×720 · WebM VP9 · 탭 소리            │
│                                           │
│ [ ⏸ 일시정지 ]  [ ■ 녹화 중지  Alt+Shift+4 ]│  ← 중지는 --c-rec
└──────────────────────────────────────────┘
```

- 시간은 `startedAt` 기준 계산이므로 팝업을 닫았다 열어도 이어진다. 일시정지 중에는 시간이 멈추고 `⏸ 일시정지됨` 표시.
- 최대 시간 1분 전부터 시간 아래에 "최대 30:00에 자동 중지"를 `--c-warn`으로 표시.

### 3.5 설정 (⚙)

같은 팝업 안에서 슬라이드 전환(← 뒤로). 변경 즉시 저장, 저장 버튼 없음. 항목이 많으므로 섹션을 접을 수 있게 한다.

```text
│ ← 설정                                    │
│ ▾ 이미지                                   │
│   포맷            ( PNG ) ( JPEG )         │  세그먼트 컨트롤
│   JPEG 품질        ────●──── 92            │  JPEG일 때만
│ ▾ 녹화                                     │
│   포맷    [ WebM (VP9) ▾ ]                 │  MP4 · WebM VP9 · WebM VP8 · WebM AV1(지원 시)
│           MP4는 가장 널리 재생돼요          │  선택값에 따른 한 줄 설명
│   프레임   ( 24 ) ( 30 ) ( 60 )            │
│   해상도   ( 100% ) ( 75% ) ( 50% )        │
│   화질     ( 자동 ) ( 낮음 ) ( 높음 )        │
│   소리     [ 탭 소리 ▾ ]                    │  없음 · 탭 · 마이크 · 탭+마이크
│           마이크는 처음 한 번 권한이 필요해요  │  마이크 선택 시, 권한 없으면 [권한 허용] 버튼
│   카운트다운 ( 없음 ) ( 3초 ) ( 5초 )         │
│   최대 길이  [ 30분 ▾ ]                      │
│   녹화 중 표시 ( 없음 ) ( 테두리 ) ( 위젯 )   │
│           ⚠ 탭 녹화에서는 결과에 함께 찍혀요  │  없음 외 선택 시 --c-warn
│ ▾ 캡처 후                                  │
│   (●) 결과 페이지 열기                      │
│   ( ) 바로 다운로드     [ ] 저장 위치 묻기   │
│   ( ) 클립보드에 복사                       │
│ ▾ 녹화 후                                  │
│   (●) 결과 페이지 열기  ( ) 바로 다운로드    │
```

- 포맷 드롭다운은 `isTypeSupported` 결과로 미지원 항목을 비활성 처리하고 "이 브라우저는 지원하지 않아요"를 붙인다.
- 마이크 권한이 없는 상태에서 마이크를 고르면 [권한 허용] 버튼이 나타나고, 클릭 시 권한 페이지가 새 탭으로 열린다. 허용되면 팝업이 다시 열렸을 때 버튼이 사라진다.

## 4. 페이지 위 오버레이 (공통)

- 단일 Shadow host `<clipt-overlay>`를 `document.documentElement` 끝에 붙인다. `all: initial` 리셋 후 토큰 재선언. `position: fixed; inset: 0`으로 페이지 `zoom`·`transform`·필터 영향을 받지 않게 한다.
- 레이어 순서: 딤(영역) → 하이라이트 박스 → 라벨 → 패널·토스트·위젯.
- **안내 토스트**: 상단 중앙, 진입 시 1회 표시 후 3초 뒤 사라지고 마우스가 상단으로 가면 다시 나타남.

```text
        ┌──────────────────────────────────────────────┐
        │ 캡처할 요소를 클릭하세요   ↑↓ 범위 · Esc 취소  │
        └──────────────────────────────────────────────┘
```

- **키 힌트 표기**: `<kbd>` 스타일(배경 `--c-bg-2`, 테두리, 모노 폰트). Mac은 `⌥⇧`, 그 외 `Alt+Shift`.
- **커서**: 요소·영역 모드 `crosshair`, 패널 위 `default`.
- 종료 시 host 제거, 리스너 해제, 페이지 스타일 복원까지 하나의 `dispose()`가 담당.

## 5. 요소 선택

### 5.1 호버 (1단계)

```text
┌ div.card  320×180 ┐             ← 라벨: 박스 위 바깥, 공간 없으면 안쪽 상단
│░░░░░░░░░░░░░░░░░░░│             ← 채움 --c-hover-soft, 테두리 2px --c-hover
│░░░░░░░░░░░░░░░░░░░│
└───────────────────┘
```

- 박스는 `getBoundingClientRect` 그대로(패딩 포함, 마진 제외). 이동은 `transform`으로 애니메이션 없이 즉시.
- 라벨: `tag#id.class1.class2 W×H`. class는 2개까지, 길면 `…`. 크기는 CSS px 정수.
- 라벨은 뷰포트 밖으로 나가지 않도록 위 → 아래 → 안쪽 순으로 위치 결정.
- `<iframe>`은 프레임 전체가 하나의 요소로 잡히며 라벨에 `iframe` 표시. 내부 요소는 선택되지 않는다.

### 5.2 선택 고정 (2단계)

- 테두리 3px `--c-accent`, 채움 `--c-accent-soft`, 네 모서리에 8px L자 마커. 라벨 배경도 `--c-accent`.
- 클릭 시 120ms 동안 박스가 살짝 수축했다 복귀(선택 확인 피드백). reduced-motion이면 생략.
- 고정 후 마우스 이동에 반응하지 않는다. 호버 박스는 사라진다.

### 5.3 선택 패널 (3단계)

너비 360px, 최대 높이 뷰포트의 70%. 기본 위치는 선택 요소와 겹치지 않는 사분면 중 오른쪽 아래 우선. 헤더 드래그로 이동, 뷰포트 안으로 클램프.

```text
┌──────────────────────────────────────────────────────────┐
│ ⋮⋮  요소 선택                                        ✕   │  ← 헤더 = 드래그 핸들
├──────────────────────────────────────────────────────────┤
│ 경로                                                      │
│ body › div › div.container › [div.card] › img            │  ← 칩, 현재는 --c-accent 채움, 가로 스크롤
├──────────────────────────────────────────────────────────┤
│ 범위          상위 ◀ ───────●───────── ▶ 하위    4 / 6   │  ← 슬라이더, 깊이/전체
├──────────────────────────────────────────────────────────┤
│ div.card                                        320×180  │  ← 모노, id/class는 보조색
│ #main-card · .card .card--featured                       │
├──────────────────────────────────────────────────────────┤
│ [    ◱ 캡처    ]   [ 다시 선택 ]   [ 취소 ]                │  ← primary / secondary / ghost
│ Enter 캡처 · ↑↓ 범위 · ←→ 형제 · Esc 뒤로                 │  ← 푸터 힌트, --fs-xs
└──────────────────────────────────────────────────────────┘
```

- **경로 칩**: 클릭 시 해당 깊이로 이동. 현재 칩이 항상 보이도록 자동 스크롤. 칩 호버 시 페이지의 해당 요소를 점선으로 미리 표시하고 마우스가 떠나면 사라짐.
- **슬라이더**: 눈금 = 경로 길이. `input[type=range]`를 감싸고 접근성 라벨 "선택 범위 깊이" 제공. 값 변경마다 하이라이트·정보·칩 즉시 갱신.
- **형제 이동(←/→)**: 이동 후 경로가 재계산되어 칩 목록이 바뀐다. 바뀌는 순간 칩 영역이 짧게 깜빡여 변경을 알린다.
- **녹화 모드**: 제목 "녹화할 요소 선택", 주 버튼 `● 녹화 시작`(`--c-rec`), 푸터 힌트 "Enter 녹화 시작". 버튼 위에 현재 프로파일 한 줄(`WebM VP9 · 30fps · 탭 소리`).
- **요소 따라가기(녹화 모드만)**: 버튼 줄 위에 스위치 한 줄. 제목 "요소 따라가기" 아래에 지금 상태가 무엇을 하는지 한 줄로 설명한다(켬 "스크롤하거나 요소가 움직여도 따라가요", 끔 "지금 화면 위치를 그대로 녹화해요"). 기본 켬, 마지막 선택을 기억한다. `role="switch"`, 줄 전체가 클릭 영역.
- **다시 선택**: 고정 해제 → 호버 단계. 패널은 닫힌다.
- 패널이 요소를 가리면 요소 라벨 옆에 "패널을 끌어 옮길 수 있어요" 힌트를 한 번 보여준다.

### 5.4 키보드 요약

| 키 | 호버 단계 | 고정 단계 |
| --- | --- | --- |
| 클릭 | 고정 | 무시(패널 밖 클릭은 페이지에 전달되지 않음) |
| ↑ / ↓ | – | 상위 / 하위(경로 내) |
| ← / → | – | 이전 / 다음 형제 |
| Enter | – | 캡처 / 녹화 시작 |
| Esc | 종료 | 고정 해제 → 호버 |
| Tab | – | 패널 내 포커스 순환 |

```text
░░░░░░░░└────────────────────────┘░░░░░░░░░░
░░░░░░░░  640×360                 ░░░░░░░░░░   ← 크기 라벨, 드래그 중 실시간
░░░░░░░░  [ ◱ 캡처  Enter ] [ 취소 Esc ]  ░░   ← 확정 바(영역 아래, 공간 없으면 위/안쪽)
```

- 드래그 시작 전에는 딤 없이 크로스헤어와 십자 가이드라인(전폭·전고 1px 점선)만 표시해 정확한 시작점을 잡게 한다.
- 드래그 중 `Shift`는 정사각형 고정, `Space`는 영역 이동.
- 확정 전 핸들로 조정 가능. 방향키로 1px, `Shift+방향키`로 10px 이동.
- 8px 미만 드래그는 클릭으로 간주해 무시(실수 방지).
- 드래그 중 포인터가 화면 위·아래 가장자리(32px)에 닿으면 가까울수록 빠르게 자동 스크롤하고, 선택은 문서 좌표로 이어진다. 뷰포트보다 큰 영역은 스티칭으로 한 장이 된다. 가로는 현재 보이는 너비 안으로 제한한다.
- 휠로 스크롤해도 선택 상자는 문서 위치를 따라간다.
- 녹화 모드에서는 확정 버튼이 `● 녹화 시작`이고, 확정 바에 프로파일 한 줄이 붙는다.

## 7. 진행·녹화·완료 피드백

| 상황 | 페이지 | 배지 | 팝업 |
| --- | --- | --- | --- |
| 전체 페이지 캡처 중 | 상단 토스트 "전체 페이지 캡처 중 3 / 12 · Esc 중단" + 얇은 진행 바 | `3/12` | 진행 화면 |
| 카운트다운 | 중앙 원형 안 숫자 3→2→1(각 1초, 페이드), 위에 "영역 녹화 시작 · Esc 취소" | – | – |
| 녹화 중 (`indicator: none`) | 없음 | `REC` 빨강 고정(깜빡임 없음) | 3.4 화면 |
| 녹화 중 (`border`) | 녹화 영역 테두리 2px `--c-rec`. 영역·요소 모드는 크롭 경계 바깥에 그려 결과에 미포함 | `REC` | 3.4 화면 |
| 녹화 중 (`widget`) | 아래 위젯 | `REC` | 3.4 화면 |
| 일시정지 | 위젯·테두리가 `--c-warn`으로 바뀜 | `⏸` | "일시정지됨" |
| 다운로드·복사 완료 | – | `✓` 초록 2초 | – |
| 축소 캡처 | 토스트(경고색) "페이지가 길어 70%로 축소해 캡처했어요" | – | 결과 페이지 배너 |
| 실패 | 토스트(경고색) 사유 + [다시 시도] | `!` 2초 | 다음 오픈 시 상단 배너 |

### 녹화 위젯 (`indicator: widget`)

```text
                                   ┌──────────────────────────┐
                                   │ ● 00:42   ⏸   ■          │  ← 우하단, 드래그 이동, 반투명 배경
                                   └──────────────────────────┘
```

- 영역·요소 모드에서는 크롭 영역 밖(가장 가까운 여백)에 자동 배치. 여백이 없으면 안쪽에 두고 팝업 설정에 경고가 이미 표시된 상태.
- 마우스를 올리면 불투명, 떼면 60% 투명으로 돌아가 페이지 가림 최소화.

토스트는 최대 1개, 새 토스트가 오면 교체. 자동 소멸 4초, 오류는 수동 닫기.

## 8. 결과 페이지

전체 페이지 앱. URL `result.html?id=…`. 탭 제목 "Clipt · 영역 캡처 640×360".

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ✂ Clipt   clipt_20260917-181230_region.png ✎         [ 복사 ] [ ⬇ 다운로드 ] │
├──────────────────────────────────────────────────┬─────────────────────────┤
│                                                  │ 정보                    │
│                                                  │ 크기      640 × 360     │
│            (체커보드 배경 위 미리보기)             │ 포맷      PNG · 214 KB  │
│                                                  │ 페이지    github.com/…  │
│                                                  │ 시각      18:12:30      │
│                                                  │ 선택자    div.card > img│
│                                                  ├─────────────────────────┤
│                                                  │ 다른 포맷으로 저장       │
│                                                  │ ( PNG ) ( JPEG 92 )     │
│                                                  ├─────────────────────────┤
│  [ 맞춤 ] [ 100% ] [ − ] 100% [ + ]              │ ⓘ 새 캡처는 툴바 아이콘  │
└──────────────────────────────────────────────────┴─────────────────────────┘
```

- **파일명**: 인라인 편집(✎). 다운로드 시 그대로 사용. 확장자는 잠금.
- **다운로드**: 주요 버튼. `saveAs` 설정 반영. 완료 시 버튼이 1.5초간 `✓ 저장됨`.
- **복사**: PNG 복사 후 `✓ 복사됨`. JPEG 결과는 "PNG로 복사돼요" 툴팁. 영상은 비활성 + "영상은 클립보드 복사를 지원하지 않아요".
- **미리보기**: 맞춤/100%/줌, 드래그 패닝, Ctrl+휠 줌. 큰 이미지는 `createImageBitmap`으로 디코드해 끊김 방지.

### 영상 결과

```text
│            <video controls>                      │ 정보                    │
│                                                  │ 길이      00:42         │
│                                                  │ 해상도    1280 × 720    │
│                                                  │ 포맷      WebM VP9 · 30fps │
│                                                  │ 소리      탭 소리        │
│                                                  │ 용량      12.4 MB       │
│                                                  ├─────────────────────────┤
│                                                  │ 다른 포맷으로 저장       │
│                                                  │ [ GIF로 변환 ] (후속)    │
```

- 폴백이 일어났으면 상단 배너 "MP4를 지원하지 않는 환경이라 WebM VP9로 저장했어요".
- 레이아웃 변경으로 중단된 녹화는 배너 "페이지가 바뀌어 00:42까지 저장했어요".
- **복구 배너**: 미완료 녹화 chunk가 있으면 상단 "지난 녹화가 저장되지 않았어요 [복구] [삭제]".
- **빈 상태**: id가 없거나 만료되면 "결과가 만료됐어요. 결과는 24시간 보관돼요".
- 편집(자르기·주석)은 범위 밖. 자리에 "곧 추가"를 두지 않는다.

## 10. 접근성

- 모든 인터랙티브 요소에 보이는 포커스 링(2px `--c-accent`, 오프셋 2px). 패널이 열리면 첫 버튼으로 포커스 이동, 닫히면 원래 포커스 복원.
- 패널 `role="dialog" aria-label`, 슬라이더 `aria-valuetext="깊이 4 / 6, div.card"`, 경로 칩 `aria-current`.
- 텍스트 대비 4.5:1 이상. 보조 텍스트 `--c-fg-2`도 라이트·다크 모두 충족.
- 색만으로 상태를 구분하지 않는다: 호버/고정은 두께·마커, 녹화는 `●`, 일시정지는 `⏸`, 완료는 `✓`.
- `prefers-reduced-motion` 준수. `prefers-color-scheme` 자동 적용, 강제 테마 옵션은 후속.
