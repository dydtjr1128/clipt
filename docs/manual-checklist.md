# 수동 확인 체크리스트

자동 테스트로 확인할 수 없는 항목이다. 릴리스 전에는 전부, 평소에는 바꾼 영역에 해당하는 절만 확인하고 PR 본문 "검증"에 결과를 적는다.

준비: `npm run build` 후 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다" → `.output/chrome-mv3`. 툴바에 고정한다.

## 1. 툴바·권한 (activeTab)

- [ ] 일반 사이트에서 툴바 아이콘 → 보이는 화면 → 결과 페이지가 열린다(host 권한 없이 동작)
- [ ] 같은 탭에서 다른 사이트로 이동한 뒤 다시 아이콘을 눌러도 동작한다
- [ ] `chrome://extensions`, Chrome 웹스토어에서 팝업 메뉴가 비활성이고 안내가 보인다
- [ ] `file://` 페이지: 파일 URL 접근을 끄면 안내, 켜면 캡처된다
- [ ] 캡처 결과에 팝업이 찍히지 않는다

## 2. 단축키

- [ ] `Alt+Shift+1`·`2`·`3`으로 보이는 화면·영역·요소 캡처가 시작된다
- [ ] `Alt+Shift+4`로 탭 녹화를 시작하고 같은 키로 중지한다
- [ ] 영역 선택 중 `Alt+Shift+2`를 다시 누르면 취소된다
- [ ] `chrome://extensions/shortcuts`에서 키를 바꾸면 팝업 표시가 바뀐다

- [ ] 캡처 후 스크롤 위치와 페이지 모습이 그대로다
- [ ] 내부 스크롤을 쓰는 앱형 페이지(메일, 문서 편집기): 경고가 결과 페이지에 보인다
- [ ] Shadow DOM을 많이 쓰는 사이트에서 요소 호버·선택이 된다
- [ ] 링크·버튼 위에서 클릭해도 페이지가 동작하지 않고 선택만 된다

## 4. 녹화

- [ ] 소리가 나는 페이지를 "탭 소리"로 녹화: 녹화 중에도 소리가 들리고 결과에 소리가 있다
- [ ] 권한 페이지에서 마이크 허용 → "탭 소리 + 마이크": 결과에 두 소리가 함께 들린다
- [ ] 10분 녹화: 작업 관리자(Shift+Esc)에서 확장 메모리가 1분·10분 시점에 비슷하다
- [ ] 1080p 창에서 절반 영역 녹화: 결과가 끊기지 않는다(30fps)
- [ ] MP4로 녹화한 파일이 다른 플레이어(OS 기본 플레이어, 메신저)에서 재생된다
- [ ] 일시정지 후 재개, 녹화 중 탭 닫기, 최대 길이 도달이 기대대로 끝난다
- [ ] 녹화 중 브라우저를 강제 종료했다 다시 켜면 결과 페이지에 복구 배너가 보인다
- [ ] 녹화 중 표시 "테두리"·"위젯": 영역·요소 녹화 결과에는 찍히지 않고 탭 녹화에는 찍힌다

## 5. 결과·설정

- [ ] 다운로드 파일명과 "저장할 위치를 매번 묻기"가 설정대로 동작한다
- [ ] 클립보드 복사 후 다른 앱(메신저, 이미지 편집기)에 붙여넣기 된다
- [ ] 설정을 바꾸고 브라우저를 다시 켜도 유지된다
- [ ] 브라우저 언어를 영어로 바꾸면 팝업·패널·결과 페이지가 영어다
- [ ] 다크 모드에서 팝업·패널·결과 페이지가 읽기 쉽다

## 6. 접근성

- [ ] 팝업·선택 패널·결과 페이지를 Tab만으로 모두 조작할 수 있고 포커스 링이 보인다
- [ ] 요소 선택을 키보드만으로 끝낼 수 있다(↑↓←→, Enter, Esc)
- [ ] OS "동작 줄이기" 설정에서 애니메이션이 없다
